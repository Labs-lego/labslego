FROZENBLOCKS LISIEUX — DOSSIER À METTRE SUR GITHUB

Fichiers principaux :
- index.html : page principale
- app.js : boutique et produits, avec Boîte de tubes dans Accessoires (35 € l'unité, 67 € par lot de 2) et Briquet BIC dans Feuilles (1,50 €)
- jeu.js : module du jeu Arcade disponible
- photos/ : images fournies et emplacement des photos de produits
- boutiques/ : emplacement des photos de boutiques

INSTALLATION
1. Décompresse cette archive.
2. Dans le dépôt GitHub de l'application, remplace index.html, app.js et jeu.js par ces versions.
3. Envoie aussi les dossiers photos/ et boutiques/ (même s'ils ne contiennent pas encore toutes les images).
4. Ajoute tes photos en respectant les noms dans PHOTOS_A_AJOUTER.txt.
5. Recharge la mini-application Telegram. Si elle garde l'ancienne version, ferme-la complètement puis rouvre-la.

À SAVOIR
Le dossier contient les fichiers de code disponibles, mais pas toutes les photos/vidéos du dépôt d'origine. La maquette graphique n'est pas une image qu'on peut mettre à la place du code : il faut intégrer le design dans les fichiers HTML/CSS/JS. Cette archive conserve le fonctionnement actuel; elle ne prétend pas que la refonte visuelle complète est déjà intégrée.
