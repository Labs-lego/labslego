INSTALLATION
1. Décompresse l'archive.
2. Remplace les fichiers correspondants dans le dépôt de ton application.
3. Envoie aussi les dossiers photos/ et boutiques/.
4. Ajoute les images/vidéos manquantes listées dans PHOTOS_A_AJOUTER.txt.
5. Recharge la mini-application Telegram.

LIMITES IMPORTANTES
Cette archive rassemble les fichiers de code récupérés et les visuels disponibles, mais elle ne contient pas tous les anciens médias. Les tarifs récemment évoqués (2 g = 10 €, 4 g = 20 €, 6 g = 30 €, 8 g = 40 €, 10 g = 45 €) ne sont pas intégrés car les articles correspondants ne sont pas clairement identifiables dans le catalogue récupéré.
